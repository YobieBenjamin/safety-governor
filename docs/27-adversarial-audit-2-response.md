# Response to adversarial function audit 2 (26 October 2026)

Audit 2, team A, verdict DOES NOT HOLD, 39 problems (7 catastrophic, 15 serious, 8 moderate, 9 claims). Report and catalog:
the project's design notes and the drive (work/audits/adversarial-function/audit-2-team-a/). This file records, for every
row of that catalog, what was done, the test that pins it, the silicon or board change it needs, and what it depends on
(PROBLEM-TO-SILICON-PIPELINE.md). "Fixed in model" means the simulation now refuses the attack and a regression test
fails if it comes back; it does not mean hardware does. A fresh adversarial audit, by a team that has seen none of this,
is what closes a row.
