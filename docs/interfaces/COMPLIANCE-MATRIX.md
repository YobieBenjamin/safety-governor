# Compliance matrix: the governor against the public NVIDIA server environment

Generated from `docs/interfaces/compliance_matrix.csv` by `python -m govsim.hardware_ref.matrix` (do not edit by hand). The one command that re-checks every row is `python -m govsim.hardware_ref`.

Read this first if you build servers or work with NVIDIA's partner programme. Every row says where the requirement comes from, how far we got, and the file that proves it. **tested** means a test or a generated result in this repo fails by assertion if the row is broken. **designed** means it is in the design files but nothing runs against it. **open** means we know it is not done and say why. **members-only** and **NDA** mean the deciding document is not public: we have not read it and claim no compliance with it. Where a number came from a public secondary source instead of the members-only original, the source column says which.
