# The goal

The claim this repository exists to test is kept in one place, in the hardware-and-silicon repository:
https://github.com/YobieBenjamin/hardware-and-silicon/blob/main/goals/GOAL.md

Two properties (no consequential effect without authorization; the stop cannot be prevented), held under three
conditions (complete exits; rules that do not allow harm in small allowed steps; keys and people that cannot be
captured). Every audit of this code tries to break that claim. This file is a pointer so an auditor pointed at this
clone alone finds the claim; the text there is the source of truth and is not copied here.
