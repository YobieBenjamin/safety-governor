# The Chip That Says No: discussion

This is where people outside the project ask questions, push back, and propose ideas about
[The Chip That Says No](https://github.com/YobieBenjamin/safety-governor), Yobie Benjamin's hardware governor for AI.
It is a discussion space, not the product.

**Two kinds of writing live in different places, on purpose:**

| Whose | Where | Ownership |
|---|---|---|
| Yobie's work: the design, the code, the proofs, the experiments, the chip | The product repositories: [safety-governor](https://github.com/YobieBenjamin/safety-governor), [hardware-and-silicon](https://github.com/YobieBenjamin/hardware-and-silicon), and the others they link | Under those repositories' own licenses |
| Questions, answers, critiques and proposals from anyone else | Here, in [Discussions](../../discussions) | Each contributor keeps the copyright in what they write, shared under CC BY 4.0 (see LICENSE) |

**How the categories are used:**

- **Announcements**: Yobie's posts only. New results, published experiments, design decisions.
- **Q&A**: anyone asks; anyone answers. Mark the answer that settles it.
- **Ideas**: proposals from outside the project. An idea here stays the contributor's; if it ever shapes the product,
  the product repository says so and links back.
- **General**: everything else.

Nothing posted here becomes part of the product by being posted. When a discussion changes the design, the change
is written in the product repository in Yobie's own words, with a link to the discussion that prompted it, the way
the open questions G1, G2, A1 and I1 credit the comments that raised them.

and the open questions in [docs/18](https://github.com/YobieBenjamin/safety-governor/blob/main/docs/18-viability-and-open-questions.md).
