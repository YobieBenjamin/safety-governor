# External audit, 22 October 2026

An independent reviewer audited the public snapshots and found real failures. This folder keeps
the whole exchange on the record, criticism included, because a program that only publishes the
reviews it survived is not doing science.

| File | What it is |
|---|---|
| [MEMO.md](MEMO.md) | The reviewer's memo, verbatim and unedited |
| [RESPONSE.md](RESPONSE.md) | Our answer, finding by finding: the reproduction, the cause, the fix, the tests, the links pinned to the fix commits, and what is still open |
| [STATUS.md](STATUS.md) | Every finding with five statuses kept apart: implemented, locally tested, propagated, rechecked, still open; research and physical findings with their own dispositions |
| [EVIDENCE.md](EVIDENCE.md) | Each fix reverted on its own: its regressions must fail by assertion (never an interface error) and the legitimate operation must still pass. Generated by `tools/audit_evidence.py` |
| [AGR-CORRECTIONS-DRAFT.md](AGR-CORRECTIONS-DRAFT.md) | The research corrections his memo calls for, drafted for autonomic-graph-regulation's `CORRECTIONS.md` |
| the scripts below | Each finding tested on the snapshot it was made against, before anything was fixed, and again after |

The account in the design record is section 9 of `docs/REVIEW-2026-10-22-fact-check.md`.

**One command checks all of it:** `bash tools/verify_audit_fixes.sh` (from safety-governor, with
hardware-and-silicon cloned beside it). It runs every test suite, every proof, both attack sweeps,
the harness and the halt-loop circuit simulation on the fixed code; runs every reproduction script
against the fixed code (each must print NOT reproduced) and against the audited snapshots `dccc1e0`
and `11eb119` in throwaway worktrees (each must print REPRODUCED); and runs the new regression tests
against the old snapshot, where they must fail. It exits non-zero and names the check if anything
does not hold. The first version (`911672b`) called plain `python3` and failed on a Mac; from `28927e3` it builds each repository's `.venv` and, from a cold start, reports 18 of 18. With finding 2 put back on purpose it goes red.
