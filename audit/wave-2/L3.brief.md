# L3 · Widen the abstract machine: budgets and rate windows, k-of-n approvals, buffer classes, egress release, loop beacon and clear

GitHub issue #3 in YobieBenjamin/safety-governor. Wave 2 of the experiment program (docs/20-experiment-program.md).

**Goal.** Extend the Z3 proofs so that every mechanism the governor model enforces has a theorem on the abstract machine, one file per protocol under `proofs/`: `budgets.py` (byte, compute and session hazard budgets; per-action rate windows), `approvals.py` (k-of-n human approvals on a hold; approvers scoped to a rule; a stranger cannot approve), `buffer_classes.py` (weights never cross a switch; activations only to roster peers; outputs only to the host), `egress.py` (a response is delivered only against a ticket over its hash, once), `loop.py` (a member reporting its switch open while current flows is LOOP_JUMPERED; clear needs authority, log and a neighbour).
